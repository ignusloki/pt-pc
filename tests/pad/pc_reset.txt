# (to Yes) and cross delete the save and restart the game in the same session, which closes the menu (the row is reached by its
# label, `sui pcfocus`). Run it with an empty save folder, never the real one.
# pt.exe --headless --virtual-pads --audio-offline --save-dir <empty folder> --start-floor f010 --frames 3000 --input-script tests/pad/pc_reset.txt
