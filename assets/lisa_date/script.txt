# One command per line, # starts a comment. The text of every `say`, `option` and `title` lives in text/<language>.txt under
# its key (text/eng.txt is the fallback for a key a language lacks).
#   scene <n> <title key>          a title card
#   bg <name>                      the backdrop bg_<name>.png (else .jpg)
#   music <name>|slow|stop         music.ogg or music.wav (name "music"), its slowed copy, or silence
#   expr <name>                    neutral happy shy sad angry creepy (her face, head, lean, a push-in and a light tint)
#   light <name>                   warm blush angry glitch dark dusk
#   cam <name>                     normal close face far rush
#   fx <name>                      flash heart shake glitch noglitch photo scare tear notear darken
#                                  twitch (one small) twitch_violent twitch_rare twitch_often twitch_off flicker_on flicker_off
#   say <lisa|you|none|glitch> <key> [expression]
#   wait <seconds>
#   choice <key>                   then option lines, each followed by its own indented lines, closed by `end`
#   option <key> <affection> [flag:<name>] [goto:<label>]
#   label <name> / goto <name>
#   if <affection|secrets|flag:<name>|selfie:lisa|selfie:you> <op> <number> <label>    op: < <= > >= == !=
#   selfie                         the selfie's photo mode (Lisa and you, each an expression and a head tilt), the shot, the
#                                  polaroid developing; then selfie:lisa and selfie:you hold the expressions (-2 grumpy .. 2 big grin)
#   ending good|bad|true
