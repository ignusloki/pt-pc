# Mac app icon

`pt-icon.png` is an unchanged copy of the image supplied for this integration: `PT-macOS-Dark-10241x.png`.

`pt.icns` contains the standard 16, 32, 128, 256 and 512 point icon representations, each at 1x and 2x. The 1024 pixel source is exported to an 8-bit RGBA representation for the icon container. Transparency and the supplied artwork are preserved. Both game and Setup bundles use this icon through `CFBundleIconFile`, populated before signing.
