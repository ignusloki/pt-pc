# Added Table

Puts a small wooden table in the first corridor of the hallway: its own glTF model (`Assets/mods/added_table/table.glb`, made by `tools/make_example_glb.py`, nothing of the game) and one `add` entry in `level.json`. The table is solid (`"collision": "box"`).

Copy this folder into `mods/` and start a loop.
