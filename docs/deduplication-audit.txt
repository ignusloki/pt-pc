DIFFERENCES KEPT

HDR/SDR shader policies: Enhanced HDR radiance, scene/output mapping, ScreenTonemapHdr, layer lighting and color-gamut behavior differ from Original. Color transfer approximations: Piecewise sRGB, PQ, approximate gamma-2.2 VFX conversions and HDR-specific mapping are different functions. Only equal formulas were shared.

Angle normalization: Fox wrapping, signed fmod normalization and std::remainder have different rounding/boundary behavior. The retained probe shows opposite signs at +pi for fmod/remainder and a concrete bitwise Fox/fmod difference. See kept-angle-probe.log.

Direction and vector adapters: Unnormalized game look vectors differ from normalized camera directions. glm::vec4-to-vec3 extraction and XrVector3f-to-glm conversion accept different SDK types; their typed adapters remain.

ASCII and language-aware matching: Asset-browser substring matching accepts an empty needle; controller matching rejects it; Vulkan layer matching also uses locale tolower. Voice recognition additionally folds accents and filters characters. Shared ASCII primitives do not replace these policies.

Tool string decoding: ASCII replacement decoding and Latin-1 decoding differ on bytes >= 0x80. Copies were shared within each policy, with public cstring aliases retained.

Binary-reader policies: Checked readers return a zero-initialized value for short input. Unchecked readers rely on caller bounds. The DSP U8 cursor uses pos < size rather than offset+1 <= size, which differs under size_t overflow; it stays separate. Cursor-owning adapters retain their own advancement. Private unchecked numeric instantiations were verified before redirecting them.

JSON representations and scalar coercion: Metadata JSON stores scalar text for strings/numbers/bools/null; engine JSON has typed Value fields and strict string access. StringMember is shared only within the metadata representation. The parsers and strict engine accessor remain separate.

Local-file request wrappers: FG ReadText loads the file through iterators then keeps its tail. NR ReadText seeks, reads a bounded tail and resizes to gcount. Stream-error, seeking and file-growth behavior differ. Their common network request primitive is shared; local-file wrappers remain.

Hashing errors and output mutation: Neural-rendering HashFile writes size_out from file_size before opening, while the shared file hash updates it after a successful open. Installer hashing throws on read failure. These owning wrappers remain; only identical fixed-size hex formatting is shared. Append-based installer hex formatting retains its allocation behavior.

Environment and path encodings: Native getenv bytes and UTF-8 os::GetEnv differ on Windows. Native u8string separators and generic_u8string separators also differ. Copies were shared only inside matching policies.

Delay-buffer component contracts: Public DelayLine has minimum length 1 and delayed reads; SampleDelay has minimum length 4 and cursor reads. Their identical write primitive is shared, while those contracts and storage/cursors remain independent.

Backend lifecycle and caches: DLSS ReleaseFeature resets ray_reconstruction_; neural Release resets error_logged_. Resources and state belong to different backend objects. The three Windows NGX DataPath caches keep independent first-use timing even though their directory initializer is shared. Typed FSR callbacks retain their own presenters and SDK contexts.

Command and route wrappers: Audio event/media/dialogue commands use different command types, payload fields and ownership. NR/FG installer route arguments have different work directories and result types. Asset selection, pinning, download/error policies and platform lifecycles remain separate.

Typed parsers and lookups: Settings integer/float parsers call stoi/stof; neural enum parsers use different tables and defaults. Typed finders search different collections/keys and return different types, indices or pointers. These are not interchangeable implementations.

UI type identity and comparison order: Dialog and museum Cell types remain distinct; their equal predicate is shared. Lisa-date bounds test coordinates in a different short-circuit order and retain that expression.

Diagnostic and fixture behavior: Test helpers with extra LogInfo, fflush, richer values, different punctuation or print-before-counter order stay separate.
