CHANGE
installer/Extractor/Extractor.csproj enables PublishTrimmed=true and TrimMode=full only when RuntimeIdentifier is osx-arm64 or osx-x64. Linker warnings are errors; warnings are not suppressed. The same project is used by both Mac publishing routes.
installer/Tests/Program.cs adds --extractor <executable> to run all existing PKG cases through a published process. It checks exit codes, exact diagnostics, output hashes and metadata; failed/invalid extraction must leave no output, and existing output must be preserved.
It also verifies the unknown-title and Asia archive bytes and rechecks existing files after refusal.
Failed subprocess startup, unexpected exit codes/stderr and a two-minute timeout fail the test. Shell command concatenation is not used for paths.
For native builds, tools/macos/build.py runs these tests against both published helpers as well as the untrimmed project reference. --skip-tests continues to avoid running foreign-architecture helpers.
docs/installer.md and the corresponding-source RUNTIME.txt explain trimming, rebuilding a modified library and the PublishTrimmed=false override.
